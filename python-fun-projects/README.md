# Python Fun Projects

A collection of beginner-friendly Python projects to learn coding by making cool stuff.

## Setup

1. Activate the virtual environment (already created):
   ```
   source venv/bin/activate
   ```
2. (If starting fresh) Install the libraries:
   ```
   pip install -r requirements.txt
   ```

## Projects

| # | Project | What you'll learn |
|---|---------|--------------------|
| 01 | [Guess the Number](01_guess_the_number/guess_the_number.py) | loops, input, if/else |
| 02 | [Mad Libs Generator](02_mad_libs_generator/mad_libs.py) | strings, f-strings, input |
| 03 | [Rock Paper Scissors](03_rock_paper_scissors/rock_paper_scissors.py) | functions, dictionaries, random |
| 04 | [Turtle Art](04_turtle_art/turtle_art.py) | loops, drawing graphics |
| 05 | [Quiz Game](05_quiz_game/quiz_game.py) | lists of dictionaries, scoring |
| 06 | [Password Generator](06_password_generator/password_generator.py) | strings, randomness, colored text |
| 07 | [Bouncing Ball Game](07_bouncing_ball_game/bouncing_ball.py) | pygame, game loops, animation |
| 08 | [Snake Game](08_snake_game/snake.py) | classes, game loops, collision detection, enums |

## Running a project

```
python3 01_guess_the_number/guess_the_number.py
```

Have fun and try changing the code to make each project your own!
